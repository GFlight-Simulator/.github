<h3 align="center">GFlight Simulator</h3>
<p align="center">Home cockpit hardware & software for serious flight simmers.</p>

---

### ✈️ What we build

- **Cockpit hardware**: MCP, EFIS and FMC modules designed for realistic home cockpits
- **Firmware**: ESP32-S3 based firmware with display dimming and modular command handling
- **GFlight Bridge**: A high-performance C++ bridge connecting our hardware to Microsoft Flight Simulator and third-party aircraft such as PMDG, with near-zero latency
- **GFlight Camera App**: Desktop camera control for MSFS 2020 / 2024
- **GFlight Launcher**: A single entry point for our software ecosystem

### 🛩️ Supported platforms

`MSFS 2020` · `MSFS 2024` · `PMDG` · `X-Plane` *(more coming soon)*
